我的使用建议

  1. 先刷入门题，不要一开始就追求复杂壳、VM、花指令。
  2. 每做完一道题都写复盘：保护特征、关键函数、算法逻辑、脚本和失败点。
  3. 遇到不会的题，先区分“工具不会用”“汇编看不懂”“算法没认出”“调试思路错了”是哪一类问题。
  4. 把常见模式单独整理成文章，比如 RC4、TEA、SMC、VM、APK Java 层校验等。

后续我会继续把用过的资源按方向补充完整。
